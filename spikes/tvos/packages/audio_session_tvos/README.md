# audio_session_tvos

The tvOS implementation of [`audio_session`](https://pub.dev/packages/audio_session).

> Generated by [`flutter-tvos plugin port`](https://github.com/fluttertv/flutter-tvos)
> from `audio_session`. Read `PORTING_REPORT.md` before publishing.

## Usage

This is a federated plugin implementation. Apps that already depend on
`audio_session` and target tvOS only need to add this package as a
dependency:

```yaml
dependencies:
  audio_session: ^<latest>
  audio_session_tvos: ^0.0.1
```

The plugin registers automatically via Flutter's federated registry — no
explicit imports required from app code.
