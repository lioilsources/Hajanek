# just_audio_tvos

The tvOS implementation of [`just_audio`](https://pub.dev/packages/just_audio).

> Generated by [`flutter-tvos plugin port`](https://github.com/fluttertv/flutter-tvos)
> from `just_audio`. Read `PORTING_REPORT.md` before publishing.

## Usage

This is a federated plugin implementation. Apps that already depend on
`just_audio` and target tvOS only need to add this package as a
dependency:

```yaml
dependencies:
  just_audio: ^<latest>
  just_audio_tvos: ^0.0.1
```

The plugin registers automatically via Flutter's federated registry — no
explicit imports required from app code.
